# SOC Analyst Lab

This repository documents my hands-on practice learning the responsibilities of a Security Operations Center (SOC) analyst. The goal of this lab is to simulate real-world cybersecurity monitoring and incident investigation tasks.

## Objectives

• Understand how security alerts are generated  
• Practice analyzing system and network logs  
• Identify suspicious behavior and potential threats  
• Document investigation steps clearly  
• Develop incident response thinking

## Skills Demonstrated

• Log analysis  
• Threat detection  
• Incident documentation  
• Security monitoring fundamentals  
• Analytical problem solving

## Lab Activities

### 1. Suspicious Login Investigation
Analyzing authentication logs to identify unauthorized access attempts.

### 2. Network Traffic Monitoring
Reviewing simulated network traffic to detect anomalies.

### 3. Incident Response Report
Documenting a security event and outlining response procedures.

### 4. Threat Detection Exercise
Identifying indicators of compromise within system activity logs.

## Tools Used

• Linux command line  
• Log file analysis  
• Network monitoring concepts  
• Security investigation methodology

## Purpose

This project is part of my cybersecurity portfolio to demonstrate practical security analysis and incident response thinking as I work toward becoming a Security Operations Center (SOC) analyst.
